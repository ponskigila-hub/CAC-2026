# Methodology

See README sections 4–5 and notebook. `src/forecast.py` is the shared preprocessing, pair construction, feature, and inference engine. `src/train.py` rebuilds the regional monthly dataset, tunes models using four pre-2023 validation origins, selects price and risk policies, evaluates four retrospective origins, and fits deployment artifacts. Training labels never extend beyond the origin cutoff. Price and shock models remain independent; neither uses future actual prices as input. Price shrinkage combines HGB log-ratio prediction with Persistence. Automatic model choice and horizon-specific classification thresholds are selected from validation, not retrospective metrics. The deployment thresholds and quantiles are adapted from historical OOF scores through 2025; they do not constitute independent calibration of the refit. Forecasts beyond 36 months are marked as unvalidated extrapolation. See `RESULTS.md` for performance and limitations.
